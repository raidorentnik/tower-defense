# Elemental Tower Defense

A simple tower defense game with four elemental towers: fire (burn), ice (slow), earth (stun), and wind (fast).

## Desktop version (pygame)

```
pip install pygame
python main.py
```

Controls: click to place towers, click tower buttons to switch types, space or Next Wave to start waves, A key or Ad button for rewarded ad (double damage for 30s).

## Web version

Open `index.html` in any browser. Same game, playable on mobile too.

## Monetization

The ad button is simulated. For real monetization, integrate AdMob (mobile) or a web ad network.
